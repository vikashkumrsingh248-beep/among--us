# Among Us Coding Club Website

## Quick start (including Android)
- Extract this ZIP.
- Open `index.html` in your browser. CSS and JavaScript are embedded in the HTML so the page also works when opened from many file managers.
- On Windows, you can also double-click `START_WEBSITE.bat`.

## Important
The Google Fonts import is optional; the page uses local fallback fonts if internet is unavailable. The registration form is a front-end demo and does not save or send entries.

## Publish online
Upload `index.html` to the root of a GitHub repository and enable GitHub Pages (Settings → Pages → Deploy from a branch → main → / (root)).
